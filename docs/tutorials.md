# Tutorials

One file for each task: what to type, or what to press, and what you will see. The
[README](../README.md) describes every command; `cdlbib COMMAND --help` lists its options.

|Task|Tutorial|
|-|-|
|Add a reference from an identifier, a search, a PDF, or by hand|[Add references](tutorials/adding-references.md)|
|Change an entry|[Modify references](tutorials/modifying-references.md)|
|Find entries|[Search the library](tutorials/searching.md)|
|Check formatting and citation accuracy|[Check the library](tutorials/checking.md)|
|Record or withdraw a human approval|[Human review](tutorials/human-review.md)|
|Send a change as a pull request from your fork|[Contribute a pull request](tutorials/contributing.md)|
|Make `cdl.bib` available to every manuscript; export a paper's `.bib` or `.bbl`|[LaTeX setup and export](tutorials/latex-setup-and-export.md)|
|Use the browser instead of the command line|[The web interface](tutorials/web-interface.md)|
|Set a Dartmouth Chat or OpenAI key|[API keys](tutorials/api-keys.md)|
